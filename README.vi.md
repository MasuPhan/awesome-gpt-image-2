## ⚡️ Tầm nhìn Dự án

Sau khi GPT-Image2 phổ biến rộng rãi, việc tạo ảnh bằng AI đã dịch chuyển từ câu hỏi "có tạo được ảnh không?" sang "có tạo được ảnh ổn định, kiểm soát được và tái sử dụng được không?". Dự án này chuyển đổi các ví dụ rải rác trong cộng đồng thành các tài sản Prompt-as-Code giúp các Agent và quy trình tự động hóa dễ dàng tái sử dụng.

Mục tiêu cốt lõi rất đơn giản: nén các prompt dạng văn bản xuôi thành các giao thức có cấu trúc (structured protocols). Khi bạn cần tạo ảnh hàng loạt, xây dựng hệ thống mẫu (template), hoặc quy trình sản xuất thực tế, cấu trúc này có giá trị cao hơn nhiều so với một đống ví dụ cô lập.

- 🧱 Atomic schema: chia tách chủ thể, ánh sáng, chất liệu, bố cục và chi tiết trực quan thành các thành phần có thể lắp ghép
- ⚙️ Thân thiện với quy trình (Workflow friendly): thiết kế riêng cho agent, script và hệ thống tự động hóa
- 🧬 Kiểm soát có cấu trúc: nâng cao khả năng kiểm soát bố cục, văn bản hiển thị và phân cấp thông tin

### Cài đặt nhanh cho Agent Skills

Khuyên dùng cho Claude Code, Codex, Cursor và các công cụ khác được hỗ trợ bởi [`skills`](https://www.npmjs.com/package/skills):

```bash
npx skills add freestylefly/awesome-gpt-image-2 --skill gpt-image-2-style-library --agent claude-code codex --global --yes --copy
```

Cài đặt cho tất cả các local agent được hỗ trợ:

```bash
npx skills add freestylefly/awesome-gpt-image-2 --global --all --copy
```

### Claude Code Plugin Marketplace

Chạy các lệnh sau bên trong Claude Code:

```text
/plugin marketplace add freestylefly/awesome-gpt-image-2
/plugin install gpt-image-2-style-library@awesome-gpt-image-2
```

### npm CLI

Nếu bạn ưu tiên dùng npm, cài đặt CLI sau đó đồng bộ skill vào các thư mục agent địa phương:

```bash
npm install -g gpt-image-2-style-library
gpt-image-2-style-library install all
```

Bạn cũng có thể chạy trực tiếp không cần cài đặt toàn cục:

```bash
npx gpt-image-2-style-library install all
```

Cài đặt từ GitHub Packages:

```bash
npm login --scope=@freestylefly --registry=https://npm.pkg.github.com
npm install -g @freestylefly/gpt-image-2-style-library --registry=https://npm.pkg.github.com
gpt-image-2-style-library install all
```

Lệnh `install all` sẽ ghi skill vào các thư mục local phổ biến được dùng bởi Codex và Claude Code, bao gồm `~/.codex/skills`, `~/.claude/skills`, và `~/.agents/skills`. Hãy khởi động lại phiên làm việc của agent sau khi cài đặt.

Sử dụng với một yêu cầu kiểu như:

```text
Use gpt-image-2-style-library to create an infographic prompt about Codex.
```

Để phát triển source code tại địa phương:

```bash
npm run generate:style-skill
npm run install:skill
```

Source của skill nằm tại [`agents/skills/gpt-image-2-style-library`](agents/skills/gpt-image-2-style-library/SKILL.md). Tài liệu tham khảo được tạo tự động từ [`data/style-library.json`](data/style-library.json), giúp website và workflow của Agent chia sẻ chung một thư viện phong cách.

```bash
VITE_GA_MEASUREMENT_ID=
GA4_PROPERTY_ID=
GOOGLE_ANALYTICS_CLIENT_ID=
GOOGLE_ANALYTICS_CLIENT_SECRET=
GOOGLE_ANALYTICS_REFRESH_TOKEN=
```

Danh mục kiểm tra thiết lập (Checklist):

- Apply [`supabase/migrations/202605090001_user_credits.sql`](supabase/migrations/202605090001_user_credits.sql) vào project Supabase.
- Apply [`supabase/migrations/20260509090000_membership_billing.sql`](supabase/migrations/20260509090000_membership_billing.sql) để thêm gói thành viên, gói credit, bản ghi đơn hàng Stripe và các RPC điều chỉnh credit.
- Apply [`supabase/migrations/20260721090000_alipay_webpay.sql`](supabase/migrations/20260721090000_alipay_webpay.sql) trước khi bật thanh toán Alipay, sau đó cấu hình giá CNY đã duyệt cho từng gói credit. Xem [Thiết lập thanh toán web Alipay](docs/alipay-web-payment.md).
- Apply [`supabase/migrations/20260722090000_paid_community.sql`](supabase/migrations/20260722090000_paid_community.sql) trước khi bật cộng đồng trả phí. Giữ `COMMUNITY_PAYMENT_ENABLED=false` cho đến khi hoàn thành QR bảo vệ, onboarding Alipay và kiểm tra thanh toán/hoàn tiền thực tế. Xem [Sổ tay vận hành cộng đồng trả phí](docs/paid-community.md).
- Apply [`supabase/migrations/20260512090000_google_account_center.sql`](supabase/migrations/20260512090000_google_account_center.sql) để thêm tổng quan sử dụng tài khoản và trừ credit bắt buộc cho super admin.
- Apply [`supabase/migrations/20260512143000_pricing_admin_metrics.sql`](supabase/migrations/20260512143000_pricing_admin_metrics.sql) để cập nhật danh mục `$5 / 300 credits` và thêm chỉ số bảng điều khiển admin.
- Apply [`supabase/migrations/20260515090000_case_favorites.sql`](supabase/migrations/20260515090000_case_favorites.sql) để thêm tính năng lưu case yêu thích cho từng người dùng.
- Thêm `https://gpt-image2.canghe.ai` và các URL dev local như `http://127.0.0.1:5173` vào Supabase Auth redirect URLs.
- Bật Google Provider sau khi thêm thông tin Google OAuth trong Supabase Dashboard.
- Để bắt buộc chỉ đăng nhập bằng Google, tắt Email Provider trong cài đặt Supabase Auth.
- Chỉ giữ `SUPABASE_SERVICE_ROLE_KEY` trong môi trường phía server như Vercel Environment Variables.
- Cấu hình Stripe Checkout với webhook URL `https://gpt-image2.canghe.ai/api/billing/webhook`.
- Đăng ký Stripe webhook nhận các sự kiện `checkout.session.completed`, `invoice.payment_succeeded`, `customer.subscription.updated`, và `customer.subscription.deleted`.
- Chỉ giữ `STRIPE_SECRET_KEY` và `STRIPE_WEBHOOK_SECRET` trong Vercel Environment Variables phía server.
- Tạo một GA4 property cho `gpt-image2.canghe.ai`, thêm measurement ID vào `VITE_GA_MEASUREMENT_ID`, và sao chép numeric property ID vào `GA4_PROPERTY_ID`.
- Tạo Google OAuth Web Client với `http://localhost:8080/oauth2callback` làm redirect URI được ủy quyền, sau đó thêm `GOOGLE_ANALYTICS_CLIENT_ID` và `GOOGLE_ANALYTICS_CLIENT_SECRET` vào `.env.local`.
- Chạy `npm run ga4:oauth`, mở URL được tạo ra, chấp nhận quyền `analytics.readonly`, dán callback URL vào terminal, sau đó thêm `GOOGLE_ANALYTICS_REFRESH_TOKEN` thu được vào Vercel dưới dạng biến Sensitive environment.

## Lời Cảm ơn & Nguồn Tham khảo

Trong quá trình thu thập và nghiên cứu, dự án này có tham khảo nội dung thư viện prompt công khai từ [YouMind](https://youmind.com/) và [OpenNana](https://opennana.com/) phục vụ cho mục đích học tập, tóm tắt và nghiên cứu phương pháp luận. Bản quyền thuộc về tác giả gốc hoặc nền tảng gốc. Nếu có bất kỳ nội dung nào vi phạm hoặc không phù hợp, xin vui lòng liên hệ và chúng tôi sẽ điều chỉnh hoặc gỡ bỏ kịp thời.

## Tuyên bố Miễn trừ Trách nhiệm

Dự án này chỉ tổng hợp các prompt cộng đồng và hình ảnh ví dụ có thể truy cập công khai nhằm mục đích học tập và nghiên cứu. Dự án không tuyên bố sở hữu bất kỳ nội dung gốc nào của bên thứ ba.

Tất cả các case prompt và hình ảnh được tạo ra trong repository này ban đầu được truyền cảm hứng từ các nguồn cộng đồng công khai, đặc biệt là [YouMind](https://youmind.com/) và [OpenNana](https://opennana.com/). Mục tiêu dự án là phân tích các ví dụ hay thành các giao thức có cấu trúc tái sử dụng được phục vụ cho việc học tập, tóm tắt và thử nghiệm tự động với các đại lý mô hình lớn (large-model agents).

- Chúng tôi nỗ lực tối đa để giữ lại nguồn gốc, bao gồm profile tác giả, link bài đăng gốc và link repository gốc.
